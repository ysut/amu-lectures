# 子宮頸癌

（※ 動作確認用のサンプル問題です）

## 子宮頸癌の組織型で最も多いのはどれか。

- [ ] 腺癌
- [x] 扁平上皮癌
- [ ] 腺扁平上皮癌
- [ ] 小細胞癌
- [ ] 明細胞癌

### 解説
子宮頸癌の約 7 割は扁平上皮癌である。近年は腺癌の割合が増えている。

## 子宮頸癌の発生に最も関与するウイルスはどれか。

- [ ] EB ウイルス
- [ ] 単純ヘルペスウイルス 2 型
- [x] ヒトパピローマウイルス（HPV）
- [ ] B 型肝炎ウイルス
- [ ] サイトメガロウイルス

子宮頸癌のほとんどに、高リスク型 HPV（16 型・18 型など）の持続感染が関与している。

## 28 歳の女性。子宮頸がん検診の細胞診で HSIL と判定された。
内診・腟鏡診では、子宮頸部に肉眼的な異常を認めない。

次に行うべきなのはどれか。

- [ ] 6 か月後に細胞診を再検する
- [ ] HPV 検査のみを行う
- [x] コルポスコピー下に狙い組織診を行う
- [ ] 骨盤部 MRI を撮影する
- [ ] 子宮頸部円錐切除術を行う

### 解説
細胞診で HSIL の場合は、コルポスコピーを行い、異常所見の部位から狙い組織診を行って組織学的に診断する。
治療方針は組織診の結果に基づいて決める。
