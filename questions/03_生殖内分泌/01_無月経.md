# 無月経

（※ 動作確認用のサンプル問題です）

## 続発性無月経の女性に、まず行うべき検査はどれか。

- [x] 妊娠反応（尿中 hCG）
- [ ] 頭部 MRI
- [ ] 子宮卵管造影
- [ ] 腹腔鏡検査
- [ ] 染色体検査

### 解説
生殖年齢の女性が無月経を訴えた場合は、まず妊娠を除外する。

## 続発性無月経の患者にゲスターゲン試験を行ったところ、消退出血を認めた。
考えられる病態はどれか。

- [x] 第 1 度無月経
- [ ] 第 2 度無月経
- [ ] 子宮性無月経
- [ ] 原発性無月経
- [ ] 妊娠

### 解説
ゲスターゲン（黄体ホルモン）の投与だけで消退出血が起こる場合は、ある程度のエストロゲン分泌が保たれており、第 1 度無月経と診断する。

## 続発性無月経の定義を答えよ。

### 解答
これまであった月経が **3 か月以上** 停止したもの。
