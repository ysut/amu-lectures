# 問題の書き方

このフォルダに **Markdown ファイル（.md）を 1 講義 = 1 ファイル** で置くと、サイトに講義として表示されます。
ファイルを保存（コミット）すると、1〜2 分でサイトに反映されます。

## いちばん簡単な追加方法

1. サイト下部の **「問題を作成する（エディタ）」** を開く
2. 左側に問題を書く（右側にプレビューとエラーが表示されます）
3. **「GitHub に追加」** を押す → GitHub の画面で **「Commit changes」** を押す

GitHub で直接書く場合は、このフォルダで **Add file → Create new file** を選び、下の書き方で入力します。

## 書き方

```markdown
# 子宮頸癌

講義の説明（省略可）

## 子宮頸癌の組織型で最も多いのはどれか。

- [ ] 腺癌
- [x] 扁平上皮癌
- [ ] 小細胞癌
- [ ] 明細胞癌
- [ ] 腺扁平上皮癌

### 解説
子宮頸癌の約 7 割は扁平上皮癌である。
```

| 書くもの | 書き方 | メモ |
| --- | --- | --- |
| 講義名 | `# 講義名` | ファイルの先頭に 1 回だけ |
| 問題文 | `## 問題文` | 1 問ごとに `##` で始める。長い症例文は次の行以降に続けて書ける |
| 選択肢 | `- [ ] 選択肢` | |
| 正解の選択肢 | `- [x] 選択肢` | `[x]` が 2 つ以上あると「2 つ選ぶ」問題になる |
| 解説 | 選択肢の下に書く | `### 解説` の見出しは省略してもよい |
| 記述式（一問一答） | 選択肢を書かずに `### 解答` の下に答えを書く | 「答えを見る → 自己採点」形式になる |
| 太字 | `**太字**` | |
| 表 | `\| 列1 \| 列2 \|` | 解説に表を入れられる |
| 画像 | `![説明](images/colpo.jpg)` | 画像は `images` フォルダなどに置き、ファイルからの相対パスで書く |

- a〜e の記号や「問1」などの番号は **自動で付く** ので、書かなくて大丈夫です。
- `[x]` は全角の `[ｘ]` や `[○]` でも正解として扱います。
- `<!-- メモ -->` と書いた部分はサイトに表示されません（作問メモなどに）。
  ただし GitHub 上のファイルには残るので、リポジトリが公開の場合は誰でも読めます。

## ファイルとフォルダ

```
questions/
├── 01_産科/                ← フォルダ = カテゴリ（先頭の番号は並び順用で、表示されません）
│   ├── 01_妊娠の生理.md
│   └── 02_分娩.md
├── 02_婦人科腫瘍/
│   ├── 01_子宮頸癌.md
│   └── images/             ← 画像はここに（フォルダ名は自由）
│       └── colpo.jpg
└── _下書き.md               ← 「_」で始まるファイル・フォルダはサイトに出ない
```

- 講義は **ファイル名順** に並びます。順番を決めたいときは `01_`、`02_` のように番号を付けてください。
- `_template.md` はコピー用のひな形です（サイトには表示されません）。

## エラーになったとき

書き方に誤りがあると、サイトは更新されず、前の状態のまま残ります。

- GitHub の **Actions** タブに赤い × が付き、**どのファイルの何行目が問題か** が表示されます。
- エディタに貼り付けると、同じエラーを行番号付きで確認できます。

よくある誤り：

- 正解の `[x]` がない
- `- [ ]` の `-` や `[ ]` の後ろのスペースが抜けている
- 選択肢の途中に普通の文章が入っている（選択肢は続けて書く）

## 学習記録について

学生の正解・不正解の記録は **各自のブラウザの中だけ** に保存されます（サーバーには送られません）。
問題文を書き換えるとその問題の記録はリセットされます。誤字の修正程度なら気にしなくて大丈夫です。
