# 妊娠の生理

妊娠に伴う母体の生理的変化についての問題です。（※ 動作確認用のサンプル問題です）

## 正常妊娠の妊娠後期に、非妊時と比べて低下するのはどれか。2つ選べ。

- [ ] 循環血液量
- [ ] 心拍出量
- [x] 血清クレアチニン値
- [ ] 血漿フィブリノゲン値
- [x] 末梢血管抵抗

### 解説
- 循環血液量は非妊時の約 40〜50% 増加し、心拍出量も増加する。
- 腎血漿流量と糸球体濾過量（GFR）が増えるため、**血清クレアチニン値は低下**する。
- 血管が拡張し、**末梢血管抵抗は低下**する。
- フィブリノゲンなどの凝固因子は増加し、血液は凝固しやすい状態になる。

## 血中 hCG 濃度が最も高くなる時期はどれか。

- [ ] 妊娠 4 週
- [x] 妊娠 8〜10 週
- [ ] 妊娠 16 週
- [ ] 妊娠 28 週
- [ ] 妊娠 36 週

### 解説
hCG は妊娠初期に急増し、妊娠 8〜10 週ごろに最高値となった後、低下する。

## 正期産の定義を答えよ。

### 解答
**妊娠 37 週 0 日から 41 週 6 日まで**の分娩。

| 区分 | 時期 |
| --- | --- |
| 流産 | 妊娠 22 週未満 |
| 早産 | 妊娠 22 週 0 日〜36 週 6 日 |
| 正期産 | 妊娠 37 週 0 日〜41 週 6 日 |
| 過期産 | 妊娠 42 週 0 日以降 |
